# Nocturnab's Homebrew tap

Mac apps by Nocturnab, installable with [Homebrew](https://brew.sh).

```bash
brew install --cask danielnebreja24/tap/purrlet
```

| App | What it is |
| --- | --- |
| [Purrlet](https://purrlet.nocturnab.com) | Your Claude and Codex usage limits in the menu bar. $2.99, needs a license key. |

The apps update themselves; `brew upgrade` is never needed. Downloads come
from each app's public releases on GitHub, signed and notarized by Apple.
